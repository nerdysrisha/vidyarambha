Confidential Computing — nested layer view

each layer lives inside the one below it · outermost = most fundamental

L0 Physical hardware — root of trust · trust this blindly ROOT OF TRUST
CPU die (Intel Xeon TDX / AMD EPYC SEV-SNP) DRAM (Samsung / SK Hynix) Memory Encryption Engine (MEE/TME) NIC · NVMe · Server chassis (HPE / Dell)
L1 Low-level firmware & management — first code on power-on · anchors attestation chain MFR TCB
BIOS / UEFI (AMI / Insyde) CPU microcode (Intel / AMD) BMC / iDRAC / iLO — persistent attack surface
L2 Hypervisor / Host OS / VMM — CSP-controlled · treated as hostile ⚠ UNTRUSTED
KVM + QEMU · VMware · Hyper-V · Xen Host OS (Ubuntu / RHEL) Cloud control plane (IBM VPC / EC2 / Azure Fabric)
L3 TEE — confidential VM (cVM) — hardware-encrypted · hypervisor sees only ciphertext MFR TCB CORE
VM firmware (OVMF) — must be measured Guest OS + bootloader (RHEL / Ubuntu · GRUB2) vTPM — must be inside cVM Attestation agent — collects Quote / Report Kata runtime + cloud-api-adaptor (containers only)
L4 Pod & container runtime — runs inside TEE · image must be signed USER TCB
Kubernetes pod (K8s / OpenShift) OCI container (signed — Sigstore / Notary) containerd / CRI-O Image signature policy
L5 User workload & services — your app · if CSP service used here, CC guarantees weaken USER TCB
App runtime (Java / Python / Go) Libraries & dependencies User-controlled KMS (HashiCorp Vault) ⚠ CSP KMS / IAM / DB — expands trust to CSP
↕   attestation evidence flows out · secrets flow back in   ↕
Quote / attestation report ↑    secret keys ↓
L6 User-provided trustee — lives outside the cloud provider · operator-controlled · never CSP TRUSTED 3RD PARTY
Attestation verifier (Veraison / IBM Attest Svc / MAA) Key Broker Service — KBS (releases keys post-attestation only) Secret store (HashiCorp Vault) Policy engine (OPA / Rego)
Read it as: L5 (your workload) runs inside L4 (container) · inside L3 (TEE / cVM) · inside L2 (hypervisor, untrusted) · inside L1 (firmware) · inside L0 (hardware). L6 lives outside the entire stack — it is the independent party that verifies the TEE and releases secrets. If the CSP controls L6, the model collapses.
