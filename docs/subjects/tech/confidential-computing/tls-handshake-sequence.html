What is the RSA signature exactly?
CA signs your cert:
CA takes your RSA public key
runs it through SHA256 hash
encrypts hash with CA's private key
→ this encrypted hash = signature
appended to your certificate
Browser verifies signature:
decrypts signature with CA public key
(CA public key is in browser by default)
gets back the hash
hashes your public key itself
compares → if match = cert is genuine
Server signs EC key:
server hashes its ephemeral EC public key
encrypts hash with RSA private key
→ signature proves server owns RSA cert
browser verifies using RSA public key
from certificate
