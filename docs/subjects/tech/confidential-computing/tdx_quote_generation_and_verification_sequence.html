TDX Quote Generation & Verification — Sequence Diagrams

End-to-end flow: TD guest generates quote.dat → host verifies via DCAP / PCCS / Intel PCS
PART 1 TDX Quote Generation
test_tdx_attest.c · PeerPod/podvm (TD guest) → tdx-attest lib → /dev/tdx-attest → TDX Module (CPU) → QE → quote.dat
↓
quote.dat is now written to disk by the TD guest.
The host (or any verifier) reads that binary blob and runs the verification path below.
PART 2 TDX Quote Verification
quote.dat → tdx_verify → DCAP lib → QCNL Config → PCCS → Intel PCS
