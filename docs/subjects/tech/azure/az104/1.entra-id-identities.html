Manage Microsoft Entra ID Identities AZ-104

Azure must know who you are before it lets you do anything. Microsoft Entra ID is the service that knows. This page covers users, guests, groups, devices, tenants and hybrid sync. Orange tags show the closest AWS equivalent.

Entra ID = identity (who). RBAC = permissions (what). They are separate systems.

  • Entra ID is Azure's sign-in and identity service (old name: Azure Active Directory). AWS: IAM + IAM Identity Center
  • Tenant = your organization's own Entra ID space. It is a directory of identities, not a billing container. AWS: closest is the IAM of an account or an Organization, but a tenant spans many subscriptions

2. The identities

  • Member user: account created in your tenant (an employee). AWS: IAM user
  • Guest user (B2B): an outsider invited by email who signs in with their own login. You invite, you do not create. AWS: federated user or cross-account role
  • Group: a bundle of users or devices. Give access once, to the group. AWS: IAM group
  • Service principal / managed identity: identity for an app or VM, not a person. Managed identity has no password to store. AWS: IAM role, instance profile
  • Device: a registered computer or phone. AWS: no direct equivalent

3. User lifecycle

  • Create: UPN (sign-in name), display name, password. Set usage location before assigning a licence.
  • Modify: edit job title, department, manager; reset password; block sign-in. Job title and department can drive dynamic groups.
  • Delete: goes to Deleted users for 30 days and can be restored. After that it is gone for good.
  • Bulk: Bulk create, Bulk invite and Bulk delete all use a downloaded CSV template. Fill it, upload it, check the result under Bulk operation results.
  • Licences: assign to a user or, better, to a group (group-based licensing). Needs Entra ID P1.

4. Groups

Two ways to fill a group. AWS: no dynamic groups; closest idea is tag-based access control

  • Security group = access to resources. Microsoft 365 group = shared mailbox, Teams, SharePoint.
  • Owner manages the group's members. A group that can hold Entra roles must be Assigned.
  • Expiration policy: owners must renew the group every X days or it is deleted (soft delete 30 days). Naming policy: required prefix or suffix and blocked words. Both apply to Microsoft 365 groups.

5. Tenants and directories

  • One person can sit in many tenants. Use Switch directory (top-right gear) to move between them.
  • Create a new tenant: Entra ID → Manage tenants → Create → type Entra ID, give an organization name and an initial domain (name.onmicrosoft.com).
  • A subscription trusts one tenant at a time. You can change it (Change directory), but roles and managed identities are lost.
  • Custom domains (like contoso.com) must be verified with a DNS TXT record.

6. Devices

  • Entra registered: personal device (BYOD), user signs in with a work account.
  • Entra joined: company device, cloud only, no on-premises AD needed.
  • Hybrid joined: company device joined to on-premises AD and also known to Entra ID.

7. Hybrid identity

  • Entra Connect (or lighter Cloud Sync) copies on-premises AD users and groups to Entra ID, so one login works in both. AWS: AD Connector, AWS Managed Microsoft AD
  • Synced objects are managed on-premises. Cloud-only objects are managed in Entra ID.

8. Security features (hands-on later)

  • MFA: a second proof when signing in. AWS: MFA devices
  • SSPR: users reset their own password. Needs registered methods and a licence for write-back to on-premises.
  • Access reviews: owners periodically confirm who should keep access, good for guests. Needs P2 (Governance).

Entra ID roles (Global Administrator, User Administrator) control the directory. Azure RBAC roles (Owner, Contributor) control resources. See 02.Subscriptions-RBAC.

Good to remember for the exam

  • Guests are invited, not created. Deleted users are restorable for 30 days.
  • Set usage location before assigning a licence. Dynamic groups need P1 or P2.
  • Dynamic group = users or devices, not both. Security = access, Microsoft 365 = collaboration.
  • A subscription trusts one tenant. Hybrid join needs on-premises AD, Entra join does not.
Part 2 · Exercise

Exercise

Goal: create a member, a guest and a group, then edit, bulk-create, delete and restore. About 45 minutes.

1 Users2 Group3 Edit4 Bulk5 Delete + restore

Task 1: Users

  1. Portal → Microsoft Entra ID → Users → New user → Create new user.
  2. UPN and display name az104-user1; auto-generate password; Account enabled ticked.
  3. Properties: job title IT Lab Administrator, department IT, usage location United States. Review + create → Create.
  4. New user → Invite an external user: your own email, tick Send invite message, same job title, department and location. Invite.

Check: Users lists az104-user1 (Member) and your guest (Guest).

Task 2: Group

  1. Entra ID → Groups → New group. Type Security, name IT Lab Administrators, membership Assigned.
  2. No owners selected → pick yourself. No members selected → pick az104-user1 and the guest. Create.

Check: Members = 2, Owners = you. Dynamic only appears in the drop-down with P1 or P2.

Task 3: Edit and reset

  1. Open az104-user1 → Edit properties → change department to Operations → Save.
  2. Reset password to see the temporary password flow.

Task 4: Bulk create

  1. Users → Bulk operations → Bulk create → Download the CSV template.
  2. Add two rows (names az104-bulk1, az104-bulk2, with a password), save, upload, Submit.
  3. Check Bulk operation results and the Users list.

Task 5: Delete and restore

  1. Select az104-bulk1 → Delete. Open Deleted users → select it → Restore user.
  2. Optional: Manage tenants and Switch directory to see how multiple tenants appear.

Clean up: delete the bulk users and the group. They cost nothing, but keep the tenant tidy.

Part 3 · Test yourself

Test yourself

Try each question first. Press the button to show every answer under its question.

Check answersHide answers
  1. What is a tenant?
    Your organization's dedicated Entra ID directory. It holds users, groups, apps and devices.
  2. A subscription trusts how many tenants?
    Exactly one at a time.
  3. Is Entra ID the same as Azure RBAC?
    No. Entra ID answers who you are. RBAC answers what you can do to which resource.
  4. A licence assignment fails for a new user. Which property is probably missing?
    1. Department
    2. Job title
    3. Usage location
    4. Display name
    C. Usage location must be set before a licence can be assigned.
  5. How is a guest different from a member?
    A guest is invited and signs in with their own identity (B2B). A member is created in your tenant. AWS: guest is like a federated user or cross-account role.
  6. A guest has not accepted the invite yet. Can you add them to a group?
    Yes. The guest object already exists, so it can be added right away.
  7. Which group type is for resource access, and which for mailbox and Teams?
    Security for access. Microsoft 365 for collaboration (mailbox, Teams, SharePoint).
  8. What licence is needed for dynamic membership?
    Entra ID P1 or P2.
  9. Write a dynamic rule for everyone with job title IT Lab Administrator.
    user.jobTitle -eq "IT Lab Administrator"
  10. An engineer changes job title. What happens in an assigned group and in a dynamic group on job title?
    Assigned: nothing, membership stays. Dynamic: the user is removed or added automatically.
  11. Can one dynamic group hold both users and devices?
    No. A dynamic group holds users or devices, not both.
  12. You deleted a user 10 days ago by mistake. What do you do?
    Open Deleted users and Restore. Deleted users can be restored for 30 days.
  13. What happens to a user deleted 45 days ago?
    It is permanently deleted and cannot be restored.
  14. You must create 200 users. What is the fastest way?
    Bulk create with the CSV template, then check Bulk operation results.
  15. What does a group expiration policy do?
    Group owners must renew the group every X days, or it is deleted (recoverable 30 days).
  16. What does a group naming policy do?
    Forces a prefix or suffix and blocks certain words in group names.
  17. You change a subscription to another tenant. What is lost?
    Role assignments and managed identities, because they belong to the old tenant.
  18. How do you prove you own contoso.com when adding a custom domain?
    Add a DNS TXT record at the domain registrar, then Verify.
  19. What is the difference between Entra registered, joined and hybrid joined?
    Registered: personal BYOD. Joined: company device, cloud only. Hybrid joined: joined to on-premises AD and Entra ID.
  20. What does Entra Connect do?
    Syncs on-premises AD users and groups to Entra ID so one login works in both. AWS: AD Connector or Managed Microsoft AD.
  21. What is a managed identity and what is its AWS equivalent?
    An identity for an Azure resource with no stored password, like an IAM role or instance profile.
  22. Name an Entra ID role and an Azure RBAC role.
    Entra: Global Administrator, User Administrator. RBAC: Owner, Contributor, Reader.
  23. Who can fix an expired or locked-out guest group membership: owner or member?
    The group owner, who manages the group's members.
  24. New engineers join every month. Access must follow job title with no admin work. What do you choose and what do you check first?
    A dynamic security group on job title. First check that you have Entra ID P1 or P2 and that the job title is filled in.
  25. Which feature lets managers periodically confirm that guests still need access?
    Access reviews (needs Entra ID Governance or P2).
