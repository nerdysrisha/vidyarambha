Manage Microsoft Entra ID Identities AZ-104

Users and groups are the building blocks of every identity solution in Azure. Here you provision an internal user, invite an external guest, and put both into a security group so access can be managed in one place.

The scenario

Your organization is building a pre-production environment for testing apps and services. A few engineers are being hired to manage it, including the virtual machines. They must sign in with Microsoft Entra ID, so you provision their users and groups. To keep administration light, group membership should ideally follow job titles automatically.

The Big Picture

Task 1: Create and configure user accounts

User accounts store user data such as name, department, location and contact information.

Get oriented in the portal

  1. Sign in to the Azure portal at https://portal.azure.com.
  2. On the Welcome to Azure splash screen, select Cancel.
  3. Search for and select Microsoft Entra ID. Browse the features in the left pane.
  4. Open the Overview blade, then the Manage tenants tab.
  5. Return to the Entra ID page with the browser back button or the breadcrumb.
  6. If time allows, explore Licenses and Password reset.

Did you know? A tenant is a specific instance of Microsoft Entra ID that holds accounts and groups. You can create more tenants and Switch between them.

Task 2: Create groups and add members

A group can contain users or devices. Members are assigned in one of two ways: statically or dynamically.

  1. In the Azure portal, search for and select Microsoft Entra ID. Under Manage, select Groups.
  2. Look through the group settings in the left pane:
    • Expiration sets a group lifetime in days. After that, the owner must renew the group.
    • Naming policy lets you block words and add a prefix or suffix to group names.
  3. On the All groups blade, select + New group and enter:
SettingValue
Group typeSecurity
Group nameIT Lab Administrators
Group descriptionAdministrators that manage the IT lab
Membership typeAssigned

Note: Dynamic membership requires an Entra ID Premium P1 or P2 license. If other membership types are available to you, they appear in the drop-down.

  1. Select No owners selected.
  2. On the Add owners page, search for and select yourself (shown in the top right corner). A group can have more than one owner.
  3. Select No members selected.
  4. On the Add members pane, search for and select az104-user1 and the guest user you invited.
  5. Select Create to deploy the group.
  6. Refresh the page and confirm the group exists.
  7. Open the group and review the Members and Owners pages.

Note: Large environments hold many groups. A naming and membership plan keeps them manageable.

Good to remember for the exam

  • A tenant represents your organization and is a specific instance of Microsoft Entra ID for your internal and external users.
  • Entra ID has user and guest accounts. Each has the level of access its scope of work requires.
  • Groups combine related users or devices. The two group types are Security and Microsoft 365.
  • Membership can be Assigned (static) or Dynamic. Dynamic membership needs Entra ID Premium P1 or P2.
  • Set a usage location on a user before assigning licenses to them.
  • Group expiration and naming policy are tenant-level controls found under group settings.
