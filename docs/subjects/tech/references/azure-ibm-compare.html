Governance & Organizational Concepts

7 items
Azure ConceptAzure DefinitionIBM Cloud EquivalentIBM Cloud Definition
Management GroupA container to organize multiple subscriptions into a hierarchy for governance, policy, and compliance.Enterprise Account / EnterpriseAn Enterprise in IBM Cloud allows you to organize multiple accounts, set policies, and consolidate billing at a higher level.
SubscriptionA billing boundary and container for resources; tied to an Azure AD tenant.IBM Cloud AccountAn account is the fundamental unit of ownership, billing, and user access. All resources are created within an account.
Resource Group (RG)A logical container for grouping related resources for lifecycle management, access control, and cost tracking.Resource Group (same name in IBM Cloud)A grouping construct to organize resources within an account for access management and billing. IBM Cloud also has resource groups that function similarly to Azure's.
ResourceAn individual service instance (VM, DB, storage, etc.) deployed in Azure.Resource (Service Instance)Any service instance (VM, DB, Object Storage, etc.) created in IBM Cloud. Each resource belongs to a resource group.
Tenant / Azure AD DirectoryIdentity boundary, providing identity and access management across subscriptions.IAM (Identity and Access Management)IBM Cloud IAM defines identities, roles, and access policies across accounts and resources. Each account has its own IAM setup.
TagsKey-value pairs to organize and classify resources across subscriptions and resource groups.Tags (same concept in IBM Cloud)Key-value labels used for organizing, searching, and billing visibility across accounts/resources.
Policy / InitiativeGovernance rules applied at management group, subscription, or RG level.Access Groups & IAM PoliciesIBM Cloud applies access governance via IAM policies and access groups. Enterprises can also set quotas and guardrails at the account/enterprise level.
