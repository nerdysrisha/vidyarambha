Kanthee jhalke maal muktaaphalaanchi

Aarti 2 — Shendoor Laal Chadhaayo

Shendoor laal chadhaayo achchhaa gajmukh ko

Haath liye gud laddoo saaeen suravar ko
Mahimaa kahe na jaay laagat hoon pad ko
Jai jai jee Ganraaj vidyaa-sukhdaataa
Dhanya tumhaaro darshan meraa mat ramtaa
Jai dev jai dev

Vighn vinaashan mangal moorat adhikaaree
Koti sooraj prakaash aise chhabee teree
Gandasthal madmastak jhool shashi baharee
Jai jai jee Ganraaj vidyaa-sukhdaataa
Dhanya tumhaaro darshan meraa mat ramtaa
Jai dev jai dev
Bhaavbhagat se koee sharanaagat aave
Santati sampatti sabahee bharpoor paave
Aise tum Mahaaraaj moko ati bhaave
Gosaaveenandan nishidin gun gaave
Jai jai jee Ganraaj vidyaa-sukhdaataa
Dhanya tumhaaro darshan meraa mat ramtaa
Jai dev jai dev
