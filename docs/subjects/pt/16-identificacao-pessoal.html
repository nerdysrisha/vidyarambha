Exercícios — Identificação e caracterização pessoal

1. Profissões e artigos — complete seguindo o padrão.

Escreva a profissão nas 4 formas: masculino singular / feminino singular / masculino plural / feminino plural.

  1. Padrão -or/-ora (como professor/professora) — pintor o pintor / a pintora / os pintores / as pintoras
  2. Padrão -or/-ora — cantor o cantor / a cantora / os cantores / as cantoras
  3. Padrão -or/-ora — tradutor o tradutor / a tradutora / os tradutores / as tradutoras
  4. Padrão -o/-a (como médico/médica) — advogado o advogado / a advogada / os advogados / as advogadas
  5. Padrão -o/-a — músico o músico / a música / os músicos / as músicas
  6. Padrão -o/-a — cabeleireiro o cabeleireiro / a cabeleireira / os cabeleireiros / as cabeleireiras
  7. Padrão invariável (como jornalista) — dentista o/a dentista / os/as dentistas
  8. Padrão invariável — motorista o/a motorista / os/as motoristas
  9. Padrão invariável — economista o/a economista / os/as economistas
  10. Padrão invariável — estudante o/a estudante / os/as estudantes

2. Relações familiares — traduza.

Use as palavras da lista: filho, filha, mulher, marido, mãe, pai, sogro, sogra, irmão, irmã, cunhado, tia, avó, primo, prima, madrinha, padrinho, sobrinho, sobrinha.

  1. son filho
  2. daughter filha
  3. husband marido
  4. mother-in-law sogra
  5. brother irmão
  6. brother-in-law cunhado
  7. grandmother avó
  8. godfather padrinho
  9. niece sobrinha

3. Posse com de — complete.

Complete com a contração correta (do, dos, da, das).

  1. O livro ______ menino. (de + o) do
  2. As roupas ______ menina. (de + a) da
  3. O pai ______ rapaz. (de + o) do
  4. A mãe ______ rapazes. (de + os) dos
  5. A casa ______ raparigas. (de + as) das

Perguntas rápidas.

Perguntas curtas e frases simples. As respostas ficam escondidas.

  1. Como perguntas o nome de alguém? Como te chamas? / Como se chama?
  2. Como dizes a tua idade? Tenho ___ anos.

  4. Feminino de "primo"? prima
  5. Plural de "irmã"? irmãs
  6. Palavra para "father-in-law"? sogro
  7. "O livro do rapaz" = ? de + o rapaz
