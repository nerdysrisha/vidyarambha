2. Verbos básicos (Basic verbs)

Quick overview of the three core verbs. Detailed usage and exercises for each are in their own sections: ser → Section 3, estar → Section 4, ser vs. estar → Section 5, ter → Section 6.

ser (to be — identity, nationality, profession, origin, characteristics)

eu sou (I am) (मैं हूँ)

tu és (you are) (तुम हो)

ele/ela/você é (he/she is / you are) (वह है / आप हैं)

nós somos (we are) (हम हैं)

eles/elas/vocês são (they/you are) (वे हैं / आप हैं)

estar (to be — location, temporary states/conditions, situations at a moment)

eu estou (I am) (मैं हूँ)

tu estás (you are) (तुम हो)

ele/ela/você está (he/she is / you are) (वह है / आप हैं)

nós estamos (we are) (हम हैं)

eles/elas/vocês estão (they/you are) (वे हैं / आप हैं)

ter (to have)

eu tenho (I have) (मेरे पास है / हैं)

tu tens (you have) (तुम्हारे पास है / हैं)

ele/ela/você tem (he/she has / you have) (उसके पास / आपके पास है / हैं)

nós temos (we have) (हमारे पास है / हैं)

eles/elas/vocês têm (they/you have) (उनके पास / आपके पास है / हैं)

há (there is / there are — invariable; see Section 6 for examples)
