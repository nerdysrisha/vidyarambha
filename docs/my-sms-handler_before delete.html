💬 MySMSHandler

Allow SMS access

Needed to read, store and send messages. On Android 13+, if the Allow button does nothing: Settings → Apps → MySMSHandler → ⋮ → Allow restricted settings, then try again.

Phone inbox

New messages are copied automatically. Use this to re-scan everything (duplicates are skipped).

Backup

Saved to Downloads as MySMSHandler-backup.json. Also auto-saved once a day when an SMS arrives.
