Allow SMS access

Needed to read, store and send messages. On Android 13+, if the Allow button does nothing: Settings → Apps → MySMSHandler → ⋮ → Allow restricted settings, then try again.

Tap ▶ to run a code and see the reply here. To go through menu steps in one go, chain them, e.g. *111*1#.

Import · re-scan the phone's inbox and sent items (duplicates and messages you deleted here are skipped).
Backup · save everything to Downloads as MySMSHandler-backup.json: messages, links and USSD codes. Also saved automatically once a day when an SMS arrives.
Export · the same backup, sent through the share sheet (WhatsApp, e-mail, Drive…).
Load · pick a backup file. Missing messages, links and codes are added; nothing on this phone is replaced.
