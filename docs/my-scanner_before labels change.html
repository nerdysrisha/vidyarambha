📄 MyScanner

ℹ️ How to scan
  • Scan document: finds the page edges and cleans the page for you. Best for papers.
  • Photo: take a normal photo, then crop it yourself.
  • Gallery: pick one or more photos you already have.
  • Add page after page, then create one PDF.
  • Tap a page below to edit it.
ℹ️ Editing a page
  • ⟲ ⟳ rotate the page.
  • ✂ Crop: drag the 4 corners onto the page edges, then Apply.
  • Filters: Original, Enhance, Clean, B&W, Gray.
  • ◀ ▶ move the page earlier or later.
  • 🗑 deletes the page. Done closes the editor.

ℹ️ About the PDF
  • File name starts with today's date and time. Change it if you like.
  • A4 or Letter fits each page on a standard sheet. Fit to photo keeps each page's own shape.
  • High quality reads best. Small file is best for email.
  • Every PDF is kept in History and a copy goes to Downloads.
  • 💾 Save as lets you pick any folder or app.

ℹ️ What the icons do
  • 📄 open the PDF   📤 share it
  • 💾 save a copy where you choose
  • ✏️ rename   🗑 delete (the Downloads copy stays)
ℹ️ About filters
  • Original: the photo as it is.
  • Enhance: brighter, whiter paper.
  • Clean: removes shadows, keeps colour.
  • B&W: black text on white, smallest PDFs.
  • Gray: black and white with shades.
  • Pages from Scan document start as Original, because they are already cleaned.
